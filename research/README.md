## Status (2026-08-02)

The system is competitive but **not** SOTA under comparable configurations, and a prior
systematic push to close the gap failed — every lever landed in noise. The findings are
stronger than the scores. Current framing: **an evaluation paper, with the system as the
instrument rather than the subject.**
